Attributes

  1. href

    2. A href attribute is used to specify the URL of the page the link goes to.

    A href = "tel:1234567890" attribute is used to create a hyperlink to a phone number.

    A href = "mailto:example@example.com" attribute is used to create a hyperlink to an email address.

    A href = "_blank" attribute is used to open the link in a new tab.

    A href = "#section1" attribute is used to link to a specific section within the same page.

  2. id

    3. An id attribute is used to specify a unique identifier for an element.

  3. datetime

    4. The datetime attribute is used to specify the date and time of an element.

    example:<time datetime = "2023-10-01"> == October 1, 2023

  4. src

    5. A src attribute is used to specify the URL of the image to display.

    example: <img src="image.jpg" alt="Description">

  5. alt

    6. An alt attribute is used to specify alternative text for an image.

  6. controls

    7. A controls attribute is used to specify that the audio or video player should have controls for play, pause, and volume.

  7. title

    8. The title attribute is used to provide additional information about an element.

    example: <abbr title="World Health Organization">WHO</abbr>

    example: <abbr title="HyperText Markup Language">HTML</abbr>

  8. type

    9. The type attribute is used to specify the type of the element.

    example: <input type="text" name="username">

  9. border

    10. The border attribute is used to specify the border of a table.

    example: <table border="1"><tr><td>Cell Content</td></tr></table>

  10. colspan

    11. The colspan attribute is used to specify the number of columns a cell should span.

    example: <td colspan="2">Spanning Two Columns</td>
