Common HTML Tags

  1. <html>

    2. The <html> tag is the root element of an HTML page.

  2. <head>

    3. The <head> tag is a container for metadata (data about data) and is placed between the <html> tag and the <body> tag. Metadata typically define the document title, character set, styles, scripts, and other meta information.

  3. <title>

    4. The <title> tag defines the title of the document.

  4. <body>

    5. The <body> tag contains the visible content of the HTML page.

  5. <h1>

    6. The <h1> tag defines the most important heading.

  6. <h2> to <h6>

    7. The <h2> to <h6> tags define subheadings.

  7. <p>

    8. The <p> tag defines a paragraph.

  8. <i>

    9. The <i> tag defines italic text.

  9. <b>

    10. The <b> tag defines bold text.

  10. <u>

    11. The <u> tag defines underlined text.

  11. <hr>

    12. The <hr> tag defines a horizontal line.

  12. <br>

    13. The <br> tag defines a single line break.

  13. <code>

    14. The <code> tag defines a section of code in different font.

  14. <li>

    15. The <li> tag defines a list item.

  15. <ol>

    16. The <ol> tag defines an ordered list.

  16. <ul>

    17. The <ul> tag defines an unordered list.

  17. <div>

    18. The <div> tag wraps the entire block of content.

  18. <span>

    19. The <span> tag wraps a small portion of text.

  19. <a>

    20. The <a> tag is used to create hyperlinks.
    to open link in new tab use target="_blank".

  20. <header>

    21. The <header> tag is the introduction or title of a document or section.

  21. <main>

    22. The <main> tag is the main content of a document.

  22. <footer>

    23. The <footer> tag is a fine print or end of a document or section.

  23. <section>

    24. The <section> tag is used to group thematically related content together.

  24. <article>

    25. The <article> tag is used to define an independent, self-contained piece of content that can be distributed and reused.

  25. <aside>

    26. The <aside> tag is used to define content that is tangentially related to the content around it.

  26. <address>

    27. The <address> tag is used to define contact information for the author or owner of a document or section.

    example

    123 Main Street, Anytown, USA 12345

  27. <mark>

    28. The <mark> tag is used to highlight text.

    example: highlighted text

  28. <q>

    29. The <q> tag is used to define a short quotation.

    example: This is a short quotation.

  29. <blockquote>

    30. The <blockquote> tag is used to define a long quotation.

    example:

    This is a long quotation.

  30. <small>

    31. The <small> tag is used to define smaller text.

    example: This is smaller text.

  31. <sub>

    32. The <sub> tag is used to define subscripted text.

    example: H2O

  32. <sup>

    33. The <sup> tag is used to define superscripted text.

    example: E = mc2

  33. <time>

    34. The <time> tag is used to define a specific time or date.

    example: October 1, 2023

  34. <div>

    35. The <div> tag is used to define a division or section in an HTML document.

    it has no visual effect by default,its power comes when we apply css or javascript.

  35. <abbr>

    36. The <abbr> tag is used to define an abbreviation or acronym.

    example: WHO

    example: HTML

  36. <img>

    37. The <img> tag is used to display images on the webpage.

    example: <img src="image.jpg" alt="Description">

  37. <video>

    38. The <video> tag is used to embed video content in the webpage.

    example: <video src="video.mp4" controls>

  38. <audio>

    39. The <audio> tag is used to embed audio content in the webpage.

    example: <audio src="audio.mp3" controls>

  39. <table>

    40. The <table> tag is used to create tables in the webpage.

  40. <th>

    41. The <th> tag is used to define a header cell in a table.

  41. <tr>

    42. The <tr> tag is used to define a row in a table.

  42. <td>

    43. The <td> tag is used to define a content cell in a particular row of a table.

  43. <thead>

    44. The <thead> tag is used to define a header section in a table that usually contains column titles.

  44. <tbody>

    45. The <tbody> tag represent the main content or body of the table containing data rows.

  45. <tfoot>

    46. The <tfoot> tag is used to define a footer section in a table often used for total or summary information.

  46. <caption>

    47. The <caption> tag provides a title or description for the table usually displayed above it.

  47. <colgroup>

    48. The <colgroup> tag is used to group columns in a table for styling purposes.
